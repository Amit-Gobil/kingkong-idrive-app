## 1.0.0

Clean rebuild. KingKong is now a focused live-data app for BMW iDrive 7 / 8: five tabs — Engine, Fuel & Air, Transmission, Details, Settings — in a gold/black design, reading the engine unit (DME, UDS 22 with OBD-II fallbacks for the S58) and the gearbox unit (EGS / ZF 8HP, read-only). It never writes to the car. Drag timer, auto-logging, TuneInspect upload, VIN-lock, map switching and fault codes were removed for a simple, reliable version 1.
